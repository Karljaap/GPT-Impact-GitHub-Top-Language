\section{Descripci\'on del Experimento}

Este documento compara las estimaciones del efecto promedio del tratamiento (ATT)
obtenidas con dos implementaciones del estimador \textit{Synthetic Difference-in-Differences}
(SDID): la librer\'ia de Python \texttt{synthdid} \cite{clarke2023} y el paquete de Stata
\texttt{sdid} \cite{pailanir2022}.

\subsection*{Descripci\'on del conjunto de datos}
\begin{itemize}
  \item \textbf{Fuente}: GitHub Innovation Graph (tabla \texttt{languages})
  \item \textbf{Lenguajes}: C, C\#, C++, Go, Java, JavaScript, PHP, Python, Ruby, TypeScript
  \item \textbf{Pa\'ises tratados} ($N_{\mathrm{tr}} \approx 158$): pa\'ises con acceso a ChatGPT
  \item \textbf{Pa\'ises de control} ($N_{\mathrm{co}} \approx 29$): pa\'ises sin acceso a ChatGPT
  \item \textbf{Periodos}: $T = 16$ trimestres (Q1-2020 a Q4-2023)
  \item \textbf{Tratamiento}: \'unico inicio en Q4-2022 (trimestre~12)
  \item \textbf{Variable resultado}: pushers \'unicos por 100\,000 habitantes
\end{itemize}

\subsection*{Conclusiones}
\begin{itemize}
  \item Los ATT estimados son \textbf{pr\'acticamente id\'enticos} entre Python y Stata.
  \item Las diferencias en los errores est\'andar se deben al m\'etodo de inferencia
        (bootstrap vs placebo), no a diferencias en el estimador subyacente.
  \item Los pesos $\hat{\omega}$ convergen al mismo control sint\'etico en ambas implementaciones.
  \item Los resultados son robustos a la inclusi\'on de covariables.
  \item Se valida la equivalencia de las implementaciones Python y Stata de SDID
        para el an\'alisis del impacto de ChatGPT en GitHub.
\end{itemize}
